3-Stage Hybrid Workflow Breakdown

Stage Component Responsibility User Experience & Output
STAGE 1 Cherm MCP (Static Engine) Runs 100% deterministic AST & regex checks locally. Scans for multi-tap flaws, DB pool starvation, BOLA, crypto mistakes in < 50ms with 0 tokens. Generates local raw findings and produces cherm_audit_report.html.
STAGE 2 AI Second Opinion Filter Static linters lack semantic business context. The AI reads Cherm's raw findings against the actual codebase to eliminate false positives and validate real vulnerabilities. Refines the audit from raw pattern matches into high-confidence, verified actionable insights.
STAGE 3 Human Control Gate The user has ultimate authority. The AI never mutates or overwrites source files without explicit confirmation. The user reviews confirmed items, chooses which fixes to accept, and gives permission to write.
